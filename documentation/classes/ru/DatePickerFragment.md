# Подробное описание класса: DatePickerFragment

---

### 1. Общая информация
- **Имя класса:** `DatePickerFragment`
- **Тип:** Диалоговый фрагмент (`androidx.fragment.app.DialogFragment`, реализующий `DatePickerDialog.OnDateSetListener`)
- **Роль класса в приложении:** `DatePickerFragment` представляет собой модульный всплывающий диалог с календарем для выбора даты.
- **Взаимодействие с другими компонентами:**
  - Создается и отображается из `MainActivity` при нажатии на кнопку `bDateFragment`.

---

### 2. Переменные (поля класса)
- Класс не содержит полей.

---

### 3. Методы класса

#### Имя метода: `onCreateDialog(Bundle savedInstanceState)`
- **Тип метода:** `public`
- **Возвращаемое значение:** `Dialog` (объект `DatePickerDialog`)
- **Параметры:**

| Имя | Тип | Описание |
|-----|-----|----------|
| `savedInstanceState` | `Bundle` | Сохраненное состояние диалога. |

- **Что делает метод:**
  1. Получает текущие год, месяц и день через `Calendar.getInstance()`.
  2. Создает и возвращает экземпляр `DatePickerDialog`.
- **Когда вызывается:** Автоматически менеджером фрагментов при показе диалога.

---

#### Имя метода: `onDateSet(DatePicker view, int year, int month, int dayOfMonth)`
- **Тип метода:** `public`
- **Возвращаемое значение:** `void`
- **Параметры:**

| Имя | Тип | Описание |
|-----|-----|----------|
| `view` | `DatePicker` | Представление выбора даты. |
| `year` | `int` | Выбранный год. |
| `month` | `int` | Выбранный месяц (0-11). |
| `dayOfMonth` | `int` | Выбранный день месяца. |

- **Что делает метод:** Показывает `Toast` с выбранной датой (`dayOfMonth/month+1/year`).
- **Когда вызывается:** При подтверждении выбора даты в диалоговом окне.

---

### 4. Жизненный цикл (Fragment)
- `onCreateDialog()`: Создает диалог.
- Уничтожается при закрытии диалога.

---

### 5. Взаимодействие с интерфейсом (UI)
- Отображает системное диалоговое окно выбора даты.

---

### 6. Взаимодействие с другими компонентами
- Запускается из `MainActivity`.

---

### 7. Общая логика класса и сценарий использования
1. Пользователь нажимает "Select date in fragment".
2. `DatePickerFragment` открывает календарь.
3. Пользователь выбирает дату и нажимает OK.
4. Вызывается `onDateSet()`, выводится сообщение `Toast`.

---

### 8. Объяснение простыми словами
Представьте `DatePickerFragment` как **настольный отрывной календарь**:
- Когда вы просите показать календарь (`bDateFragment`), класс выдает вам окно с календарем на сегодняшний день.
- Вы указываете пальцем на дату, и календарь подтверждает ваш выбор!
