# Подробное описание класса: ReceiverAfterTime

---

### 1. Общая информация
- **Имя класса:** `ReceiverAfterTime`
- **Тип:** BroadcastReceiver (`android.content.BroadcastReceiver`)
- **Роль класса в приложении:** `ReceiverAfterTime` выполняет роль фонового приемника событий. Когда срабатывает будильник, запланированный в `AlarmManager`, Android пробуждает этот приемник. Он перехватывает сигнал и отображает системное уведомление с кнопками действий.
- **Взаимодействие с другими компонентами:**
  - Объявлен в `AndroidManifest.xml` через тег `<receiver>`.
  - Вызывается через `AlarmManager` с помощью `PendingIntent`.
  - Использует `NotificationChannel.CHANNEL_1_ID` для отправки уведомлений.
  - Открывает `MainActivity` при клике на уведомление.

---

### 2. Переменные (поля класса)
- Класс не содержит полей (приемник без состояния).

---

### 3. Методы класса

#### Имя метода: `onReceive(Context context, Intent intent)`
- **Тип метода:** `public`
- **Возвращаемое значение:** `void`
- **Параметры:**

| Имя | Тип | Описание |
|-----|-----|----------|
| `context` | `Context` | Контекст выполнения приемника. |
| `intent` | `Intent` | Входящий интент от `AlarmManager`. |

- **Что делает метод:**
  1. Показывает `Toast` ("Alarm triggered!").
  2. Вызывает `buildAndShowNotification(context)`.
- **Когда вызывается:** Автоматически системой Android при срабатывании `AlarmManager`.

---

#### Имя метода: `buildAndShowNotification(Context context)`
- **Тип метода:** `private`
- **Возвращаемое значение:** `void`
- **Параметры:**

| Имя | Тип | Описание |
|-----|-----|----------|
| `context` | `Context` | Контекст для создания и отправки уведомления. |

- **Что делает метод:**
  1. Подготавливает заголовок ("IMPORTANT!") и текст уведомления.
  2. Создает `Intent` для открытия `MainActivity.class`.
  3. Оборачивает интент в `PendingIntent.getActivity()`.
  4. Строит уведомление через `NotificationCompat.Builder` (иконка, заголовок, текст, приоритет, красный цвет, кнопка "Open App").
  5. Проверяет разрешение `POST_NOTIFICATIONS` на Android 13+.
  6. Отправляет уведомление через `NotificationManager`.
- **Когда вызывается:** Из метода `onReceive()`.

---

### 4. Жизненный цикл (BroadcastReceiver)
- `onReceive()` вызывается при получении сигнала. После завершения метода объект уничтожается системой.

---

### 5. Взаимодействие с интерфейсом (UI)
- Отображает `Toast` и всплывающее уведомление в строке состояния устройства.

---

### 6. Взаимодействие с другими компонентами
- Вызывается системным `AlarmManager`.
- Передает уведомление в `NotificationManager`.
- Открывает `MainActivity` при нажатии.

---

### 7. Общая логика класса и сценарий использования
1. Наступает время будильника.
2. Система разбудила `ReceiverAfterTime`.
3. `onReceive()` создает и отправляет уведомление.
4. На экране появляется всплывающее уведомление со звуком/вибрацией.
5. Пользователь нажимает на уведомление и переходит в `MainActivity`.

---

### 8. Объяснение простыми словами
Представьте `ReceiverAfterTime` как **звонаря на часовой башне**:
- Звонарь тихо спит, пока его не разбудит будильник (`AlarmManager`).
- Как только будильник звонит (`onReceive`), звонарь просыпается, бьет в колокол (показывает уведомление на экране) и передает вам записку для открытия главного приложения (`MainActivity`).
- Выполнив работу, звонарь снова отдыхает!
